Extension Installation Guide (Chrome / Edge / Brave / Arc)
Install Shine Flow Worker Extension in 60 seconds to automate video & image generation on flow.google.com
📥 Download Extension Package (.zip)
💡 Extension Advantage: Runs directly inside your real browser authenticated session without CAPTCHA checkpoints or authentication breakages, supporting both Google Workspace and personal accounts.
1
Download or Extract Folder
Click "Download Extension Package (.zip)" above and extract to a permanent folder (e.g. C:\Extensions\shine-flow-extension) or point to the project source directory:
apps/shine/services/flow-worker/extension
2
Open Extensions Management
Open a new browser tab in Chrome / Brave / Edge and navigate to:
chrome://extensions
(Or edge://extensions if using Microsoft Edge).
3
Enable Developer Mode
Look at the top-right corner of the Extensions page and toggle Developer mode ON.
4
Load Unpacked Extension
Click "Load unpacked" in the top-left corner, and select the extension folder. The Shine Flow Worker icon will appear in your browser toolbar!
Connection Configuration & Multi-Account Fleet Operations
Configure WebSocket endpoints, sync cookies for Cloud Run, and operate multiple Google Flow accounts concurrently.
A
Configure Server WebSocket URL
Click the Extension icon in your Chrome toolbar:
  • Local Development: Enter ws://localhost:8088/ws
  • Cloud Run Deployment: Enter wss://<your-flow-worker-domain>/ws
Click "Save & Reconnect". The status badge will change to Connected (Online) in green.
B
Open Google Flow Tab
Navigate to https://flow.google.com and sign in with your Google account. Keep this tab open in the background to automatically process incoming generation tasks.
C
Sync Cookies (For Headless Standby)
In the extension popup, click "Sync Cookies". The Flow session authentication will be securely synchronized to the Flow Worker server to run Headless Playwright fallbacks even if Chrome is closed!
D
Parallel Multi-Account Fleet (Multi-Profile)
Want to scale generation throughput 5x to 10x?
  1. Open Chrome ➔ Click your user avatar at the top right ➔ Select "Add Profile".
  2. Sign in with your second Google account on flow.google.com.
  3. Install the Shine Flow Worker extension in the new profile.
  4. In the extension popup, click "+ New ID" (or assign a custom name like acc_pro_02), then click "Save & Reconnect".
  5. All accounts will appear in the Fleet table. The server will automatically balance generation jobs across accounts!
Cloud Run Deployment & Shine Studio Integration
Flow Worker is standardized following the exact same architecture as demucs-worker and render-worker.
🚀 Automated 1-Click Deployment: Running Shine's Cloud Run deployment script automatically builds & deploys shine-flow-worker, captures its Service URL, and provisions the FLOW_WORKER_URL environment variable into shine-app!

1. Deploy Full Ecosystem (Main App + Demucs + Render + Flow Worker):

Linux / macOS / Cloud Shell (Bash):

./scripts/deploy-cloudrun.sh

Windows (PowerShell):

.\scripts\deploy-cloudrun.ps1

2. Deploy Flow Worker Independently:

Bash:

cd services/flow-worker && ./deploy.sh

PowerShell:

cd services/flow-worker; .\deploy.ps1

3. Environment Variable Configuration on Shine Server:

FLOW_WORKER_URL=https://shine-flow-worker-xxxx-uc.a.run.app
